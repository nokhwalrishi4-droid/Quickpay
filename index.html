Quick Start

Full step-by-step guides for HTML/JS, PHP, and Java are in API Integration, right below Quick API in the sidebar. Short version:

  1. Create an order — POST /api/developer/create-order with { quick_api, amount, title }
  2. Send the customer to the payment_url you get back
  3. Poll GET /api/developer/order-status/:orderId (same key) until status is success or failed, and show your own success/failure UI
